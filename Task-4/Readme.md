# Task 4 – Data Storytelling & Statistical Validation

## Project Overview
This project focuses on analyzing supermarket sales data and presenting insights through data storytelling and statistical validation. The goal is to transform raw data into meaningful insights that support business decision-making.

## Tools Used
- Microsoft Power BI Desktop – Data visualization and dashboard creation
- Google Colab – Statistical analysis and hypothesis testing using Python
- Microsoft PowerPoint – Presentation and data storytelling

## Dataset
The dataset used is the Supermarket Sales dataset, which contains transaction details such as product line, city, payment method, total sales, and customer ratings.

## Analysis Performed
1. Created an interactive dashboard using Power BI to visualize sales performance.
2. Analyzed sales trends across product lines, cities, and payment methods.
3. Conducted statistical hypothesis testing using Python in Google Colab.

## Hypothesis Testing
A T-test was performed to determine whether customers who use E-wallet spend more than customers who use Cash.

Results:
- T-statistic: 0.4009
- P-value: 0.6886

Since the p-value is greater than 0.05, we fail to reject the null hypothesis. This indicates that there is no statistically significant difference in spending between E-wallet and Cash customers.

## Key Insights
- Sales performance varies across product lines and cities.
- Multiple payment methods are used by customers.
- Customer ratings are generally positive.

## Conclusion
Data visualization and statistical analysis help businesses understand customer behavior and sales performance. The analysis suggests that payment method does not significantly influence customer spending.
